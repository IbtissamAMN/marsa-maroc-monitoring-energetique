# SME — Système de Monitoring Énergétique (Marsa Maroc, Port d'Agadir)

Maquette fonctionnelle (site vitrine + application) basée sur le cahier des charges du marché 12/DEPA/2026.
Les données affichées sont des données de démonstration simulées.

## Contenu
- `index.html` : site et application complets (HTML, CSS et JavaScript, sans dépendance à installer)

## Lancer en local
Ouvrir `index.html` dans un navigateur, ou : `npx serve .`

## Déploiement
GitHub puis Vercel (Framework Preset : Other, aucune commande de build, dossier de sortie : racine).
